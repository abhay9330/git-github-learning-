# Git & GitHub: A Practical Command Guide

> Learn the commands. Understand the workflow. Build confidence by practising.

Welcome! This guide is for anyone learning Git and GitHub. It explains the commands in simple language, shows how to use them, and includes practical examples to help you follow along.

You’ll find **almost all commonly used Git and GitHub commands** here—from starting a repository and tracking files to creating commits, working with branches, merging changes, and sharing your work on GitHub. Each command is explained so you can understand what it does and when to use it.

## How to Use This Guide

1. Read a section to understand the idea.
2. Try its commands in a practice repository.
3. Check the result with `git status` or `git log`.
4. Once you’re comfortable, apply what you’ve learned to your own project.

By practising as you read, you’ll learn how your changes move from your files, into commits, and then to GitHub. Keep this guide handy as a reference whenever you need a command.

**Tip:** Commands such as `rm` and `git reset --hard` can permanently remove files or changes. Try them in a practice repository first, and check where you are before running them.
